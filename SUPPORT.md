# Support

## Usage questions

Read the [guide](https://ziioai.github.io/weird64/guide/) and
[TypeDoc API reference](https://ziioai.github.io/weird64/api/) first. If the
answer is not covered, open a GitHub Discussion when Discussions is enabled.

## Bugs and feature requests

Use the repository's structured issue forms. Include the Weird64 version,
runtime, package manager, and a minimal reproduction for bugs.

## Security

Do not use public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md)
to submit a private report.

Support is provided by community availability; response times are not
guaranteed.
