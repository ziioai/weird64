# 编码格式

Weird64 将任意数量的比特编码为六位字符。

## 默认字符集

```text
0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz-_
```

索引 0 的字符表示 `000000`，索引 63 的字符表示 `111111`。

## 帧结构

对于载荷比特 `P`：

1. 使用首尾哨兵位构造 `1 P 1`。
2. 追加尽可能少的 `0`，使长度成为六的倍数。
3. 将每六位转换为字符集索引。

```text
载荷:    101
加帧:  1 101 1
填充:  110110
索引:       54
输出:        s
```

## 兼容性向量

| 输入 | 输出 |
| --- | --- |
| 空比特序列 | `m` |
| `101` | `s` |
| `101010` | `rG` |
| `00101001010` | `bAW` |

## 边界与安全

末尾哨兵位保留单个 Weird64 值的载荷长度，但无法识别直接拼接的多个值之间的边界。
请用容器格式或外部分隔符存储多个值。

Weird64 不提供机密性、完整性或真实性，不能作为加密或密码学结构的替代品。
